# Real-Time Chat Application (React + Firebase)

A futuristic real-time one-to-one chat app built using **React**, **Firebase Authentication**, and **Firebase Realtime Database**, styled with **glassmorphism and neon UI**, and deployed on the cloud using **Vercel**.

🌐 **Live App:** [https://cloudchats.vercel.app/login](https://cloudchats.vercel.app/login)

---

## 💡 What is This Project?

This project is a fully functional **cloud-based messaging app** that demonstrates the core concepts of **cloud computing**, such as:

- Hosting services on the internet
- Scalable infrastructure (auto-growing with user base)
- Real-time data communication
- User authentication and security

This app allows users to:
- Create an account (sign up)
- Log in securely using email/password
- Select a chat partner
- Exchange messages in real-time
- View timestamps for each message

---

## ☁️ Cloud Computing 

This project shows the implementation of **Cloud Computing Technologies** through the following:

- **Firebase Authentication:** A cloud identity platform for secure user login and management.
- **Firebase Realtime Database:** A NoSQL cloud database that syncs data between clients in real time.
- **Firebase Hosting (optionally Vercel):** For fast and secure static web hosting with global CDN.
- **Vercel Deployment:** A serverless platform that automates the build and deployment process.

Together, these services eliminate the need for traditional backend code and infrastructure, making the app **highly scalable, maintainable, and reliable**.

## ✨ Features

- 🔐 Secure Firebase-based authentication system
- 💬 One-to-one real-time messaging between users
- 🕒 Timestamped messages
